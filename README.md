## Projects

### [sql-interview-patterns](./sql-interview-patterns)

A learning site covering the 50 SQL interview patterns, with 10 questions each
(500 total). Answers stay hidden until you ask for them, revealed in stages —
hint, then a plain-English approach, then the SQL — so the concept has to be
reasoned about before the syntax is available. Vite + React + TypeScript,
deploys to Vercel as a static site.
